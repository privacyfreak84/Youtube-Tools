# Youtube CLI Utilities

### This repo contains a collection of CLI tools for YouTube, that can be used to produce compilations and transitions for videos.


Includes:
1. [auto_compile.py](https://github.com/privacyfreak84/Youtube-Tools/blob/main/auto_compile.py): Master script for downloading videos or shorts from a channel and stitching them into a compilation with transtitions
2. [make_transitions.py](https://github.com/privacyfreak84/Youtube-Tools/blob/main/make_transitions.py): Script to create a few basic transitions
3. [yt_toolkit.py](https://github.com/privacyfreak84/Youtube-Tools/blob/main/yt_toolkit.py): Legacy version of [auto_compile.py](https://github.com/privacyfreak84/Youtube-Tools/blob/main/auto_compile.py), but needed for it to work. Both must be in the same directory. Additionally, this script also has additional features that one may find useful for analysing competition and trends etc.
