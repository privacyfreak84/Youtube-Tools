So far, these scripts have been preliminarily created. They are pending further testing and updates

## 2026-10-01
- Added `stitch_videos.py`, which had been missing from the repo. `make_compilations.py` imports it and `auto_compile.py` depends on it through `make_compilations.py`, so the compile pipeline could not run without it.
- Rewrote `README.md` to cover all five scripts, how they depend on each other, requirements and usage.
- Smoke-tested with 3 synthetic clips (ffmpeg available, no yt-dlp): `stitch_videos.py` with fade transitions and with a stinger generated by `make_transitions.py`, and `make_compilations.py` end to end (including `--list` and `--include-leftover`). All rendered successfully with the expected durations.
- NOT yet tested: `auto_compile.py` and `yt_toolkit.py` (need yt-dlp and network access to YouTube), and the transitions other than fade and the burst stinger.

## 2026-10-02
- Fixed: `auto_compile.py` interactive mode reused the previous run's FROM/TO dates as prompt defaults while the prompt said "Enter = no limit". Pressing Enter silently kept an old range (e.g. 2026-09-30), which cut an 844-short channel down to 1 video that was already downloaded. Dates are no longer remembered between interactive runs; the prompt label now matches what Enter does.
- Fixed: `--from` / `--to` were ignored in interactive mode (only worked with a channel on the command line). They now prefill the date prompts.
- Improved: the "all downloaded" / "nothing new" / "pick doesn't match" messages now say when a date range narrowed the list.
- Tested with a faked 844-short channel (no network): the old code reproduced the reported output exactly; the fixed code plans against all 844. Also checked `--from` prefill, `-` to clear, and that one-line mode is unchanged.
